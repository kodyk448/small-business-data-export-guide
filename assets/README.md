# Images in this guide

The share image, the closing art, the “where the export lives” cards and the export-plan diagrams were made for this guide by Dakota Kronberger / Future Built Digital. The Ko-fi support banner was supplied by Dakota.

Each “where the export lives” card is a drawing of the menu path described on the vendor’s help page, not a screenshot of the product. Menus change; the vendor’s page is the authority.

Tool logos are the vendors’ site icons, collected on November 18, 2026, except the Square mark, which was redrawn at a higher resolution. The export-plan SVGs embed the same icons and are provided in desktop and mobile versions. Product names and logos belong to their respective owners.
